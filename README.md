# Kapitelweise – Startseite (GraphQL)

Dieser Service liefert alles für die Startseite und verwaltet die Mitgliedschaften.

- Zeigt mit einer einzigen Abfrage den eigenen Namen, alle eigenen Buchclubs und die offenen Einladungen.
- Neue Buchclubs gründen. Wer den Club gründet, wird Admin.
- Andere Nutzer über ihren Benutzernamen einladen.
- Einladungen annehmen oder ablehnen.
- Einen Buchclub wieder verlassen.

Wenn jemand einem Club beitritt oder ihn verlässt, gibt der Service dem Buchclub-Backend Bescheid, damit dort die richtigen Rechte gelten.
